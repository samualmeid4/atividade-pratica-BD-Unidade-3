# 📊 Atividade Prática de Banco de Dados — Unidade 3

Repositório contendo exercícios práticos de modelagem relacional, scripts de criação de esquemas (DDL) e consultas SQL avançadas (DML/DQL) em **Python** e **Django**.

---

## 🎯 Tópicos Praticados
* Normalização de dados (1FN, 2FN, 3FN).
* Definição de chaves primárias e estrangeiras com integridade referencial.
* Consultas com junções (`INNER JOIN`, `LEFT JOIN`), agregações (`COUNT`, `AVG`, `SUM`) e agrupamentos (`GROUP BY`).
